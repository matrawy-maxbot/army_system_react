# مزايا الصفحة الرئيسية الجديدة

## نظرة عامة
تم تحديث الصفحة الرئيسية بمزايا تفاعلية جديدة لتحسين تجربة المستخدم وسهولة إدارة الفاكسات.

---

## ⭐ المزايا الجديدة

### 1. زر النجمة (Favorite/Add to Lists)

#### الوصف:
زر دائري بأيقونة نجمة يظهر على كل كارت فاكس

#### السلوك:
- **مخفي افتراضياً** - يظهر فقط عند Hover على الكارت
- **ثابت ظاهر** - إذا كان الفاكس موجود في أي قائمة
- **يتغير اللون** - أزرق مملوء عندما يكون في قائمة
- **Animation smooth** - تأثيرات انتقال سلسة

#### الموضع:
- أعلى اليسار من الكارت (top: 10px, left: 10px)
- فوق صورة المعاينة
- لا يعيق النقر على الكارت نفسه

#### الوظيفة:
```javascript
onClick={(e) => {
  e.stopPropagation(); // لمنع فتح تفاصيل الفاكس
  handleAddToLists({
    type: 'fax',
    id: fax.id,
    fileName: fax.name
  });
}}
```

---

### 2. مودال تفاصيل الفاكس

#### الوصف:
نافذة منبثقة تعرض تفاصيل كاملة عن الفاكس المحدد

#### المحتويات:
1. **Header**:
   - اسم الفاكس (قابل للتعديل inline)
   - زر تعديل الاسم
   - زر النجمة (إضافة للقوائم)
   - زر فتح المجلد
   - زر الطباعة
   - زر الإغلاق

2. **معاينة الصور**:
   - عرض صور صفحات الفاكس
   - أزرار التنقل (السابق/التالي)
   - عداد الصفحات (1/10)
   - تمييز الصفحات التابعة

3. **صور مصغرة**:
   - شبكة من الصور المصغرة
   - النقر للانتقال لصفحة محددة
   - تمييز الصفحة الحالية
   - فصل بصري بين الصفحات الأساسية والتابعة

4. **الملاحظة**:
   - عرض الملاحظة الحالية
   - إضافة/تعديل ملاحظة
   - حذف الملاحظة

5. **الإجراءات السفلية**:
   - زر حذف الفاكس (أحمر)
   - زر فتح الملف (أزرق)
   - زر إغلاق (رمادي)

#### كيفية الفتح:
- النقر على أي كارت فاكس في الصفحة الرئيسية

---

### 3. مودال إنشاء رد

#### الوصف:
نافذة لاختيار قالب وإنشاء رد على الفاكس

#### المحتويات:
- عنوان: "اختر قالب للرد"
- قائمة بالقوالب المتاحة
- خيار "مستند فارغ"
- أزرار: تأكيد / إلغاء

#### كيفية الفتح:
- النقر على زر "+ إنشاء رد لهذا الفاكس" في كارت الفاكس

#### العملية:
1. User ينقر "إنشاء رد"
2. المودال يفتح ويعرض القوالب
3. User يختار قالب
4. يتم إنشاء رد جديد:
   ```javascript
   {
     id: `reply-${Date.now()}`,
     faxId: faxId,
     name: `رد - ${template.name}`,
     templateId: template.id,
     status: 'draft',
     createdDate: new Date().toISOString()
   }
   ```
5. الرد يضاف إلى `appState.faxReplies`
6. Toast notification يظهر
7. الكارت يحدث تلقائياً لعرض الرد

## 🎨 التصميم البصري

### زر النجمة (Star Button)

```css
/* الحالة الافتراضية - مخفي */
.fax-star-btn {
  opacity: 0;
  transform: scale(0.8);
}

/* عند Hover على الكارت */
.fax-card:hover .fax-star-btn {
  opacity: 1;
  transform: scale(1);
}

/* عندما يكون في قائمة */
.fax-star-btn.in-list {
  opacity: 1;
  background: #edf3ff;
  border-color: #3478f6;
}
```

#### المظهر:
- **الحجم**: 32x32px دائري
- **الخلفية**: بيضاء شبه شفافة مع `backdrop-filter: blur(4px)`
- **الحدود**: 1px solid #e7ebf1
- **الأيقونة**: نجمة 18x18px
- **Shadow**: `0 2px 8px rgba(0, 0, 0, 0.08)`

#### الحالات:
1. **Default (hidden)**: `opacity: 0, scale(0.8)`
2. **Hover card**: `opacity: 1, scale(1)`
3. **Hover button**: `scale(1.1), border: blue`
4. **In list**: `background: blue-soft, icon: blue, filled`
5. **Active**: `scale(0.95)`

## 🔄 تدفق العمل (Workflows)

### Workflow 1: إضافة فاكس إلى قائمة

```
┌─────────────────────────────────────────────────────┐
│ 1. User hovers على كارت الفاكس                     │
│    → زر النجمة يظهر (fade in + scale)             │
└────────────────────┬────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────┐
│ 2. User clicks زر النجمة                           │
│    → stopPropagation() (لا يفتح تفاصيل الفاكس)    │
│    → handleAddToLists() يُستدعى                   │
└────────────────────┬────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────┐
│ 3. AddToListsModal يفتح                            │
│    → يعرض القوائم المتاحة                          │
│    → User يختار قائمة واحدة أو أكثر               │
└────────────────────┬────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────┐
│ 4. الفاكس يضاف إلى القوائم المحددة                │
│    → appState.lists يتحدث                         │
│    → البيانات تحفظ                                 │
└────────────────────┬────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────┐
│ 5. زر النجمة يتحدث                                │
│    → يصبح أزرق مملوء                               │
│    → يبقى ظاهر (حتى بدون hover)                   │
│    → Toast notification يظهر                       │
└─────────────────────────────────────────────────────┘
```

### Workflow 2: عرض تفاصيل الفاكس

```
┌─────────────────────────────────────────────────────┐
│ 1. User clicks على كارت الفاكس                     │
│    → handleFaxCardClick(fax.id) يُستدعى           │
└────────────────────┬────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────┐
│ 2. FaxDetailModal يفتح                             │
│    → selectedFaxId يُحدد                           │
│    → showFaxDetail = true                          │
└────────────────────┬────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────┐
│ 3. المودال يحمل بيانات الفاكس                     │
│    → appState.filteredFaxes.find(id)               │
│    → يعرض الصور والملاحظات                        │
└────────────────────┬────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────┐
│ 4. User يمكنه:                                     │
│    → تعديل الاسم                                   │
│    → إضافة/تعديل ملاحظة                           │
│    → التنقل بين الصور                              │
│    → طباعة الفاكس                                  │
│    → إضافة لقوائم                                  │
│    → حذف الفاكس                                    │
└─────────────────────────────────────────────────────┘
```

### Workflow 3: إنشاء رد على فاكس

```
┌─────────────────────────────────────────────────────┐
│ 1. User clicks "إنشاء رد لهذا الفاكس"              │
│    → handleCreateReply(fax.id) يُستدعى            │
│    → tempSelectedFaxId = fax.id                    │
└────────────────────┬────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────┐
│ 2. SelectTemplateModal يفتح                        │
│    → يعرض قوالب الردود المتاحة                    │
│    → خيار "مستند فارغ"                             │
└────────────────────┬────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────┐
│ 3. User يختار قالب                                 │
│    → handleTemplateSelected(template) يُستدعى     │
└────────────────────┬────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────┐
│ 4. رد جديد يُنشأ                                   │
│    → id: reply-{timestamp}                         │
│    → faxId: tempSelectedFaxId                      │
│    → name: "رد - {template.name}"                  │
│    → status: 'draft'                               │
└────────────────────┬────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────┐
│ 5. الرد يضاف إلى appState                          │
│    → faxReplies: [...oldReplies, newReply]        │
│    → البيانات تحفظ                                 │
└────────────────────┬────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────┐
│ 6. واجهة الكارت تتحدث                              │
│    → زر "إنشاء رد" يختفي                           │
│    → يظهر بدلاً منه:                               │
│      - أيقونة Word                                 │
│      - "رد فاكس X"                                 │
│      - badge "مسودة"                               │
│    → Toast notification يظهر                       │
└─────────────────────────────────────────────────────┘
```
