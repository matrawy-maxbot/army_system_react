## التدفق الوظيفي

### سيناريو 1: إضافة رد لأول مرة
```
1. المستخدم يضغط "إضافة رد"
   ↓
2. نافذة اختيار الفاكس (لأنه لم يتم اختيار فاكس)
   ↓
3. المستخدم يختار فاكساً
   ↓
4. نافذة اختيار القالب
   ↓
5. المستخدم يختار قالباً أو مستند فارغ
   ↓
6. يُنشأ الرد ويُعرض في القائمة
   ↓
7. رسالة نجاح
```

### سيناريو 2: إضافة رد (فاكس محدد مسبقاً)
```
1. المستخدم يضغط "إضافة رد"
   ↓
2. نافذة اختيار القالب مباشرة
   ↓
3. المستخدم يختار قالباً
   ↓
4. يُنشأ الرد ويُعرض في القائمة
```

### سيناريو 3: إدارة رد موجود
```
1. المستخدم يضغط على بطاقة الرد
   ↓
2. نافذة التفاصيل الكاملة
   ↓
3. المستخدم يمكنه:
   - تعديل الاسم
   - تغيير الحالة
   - إضافة/تعديل ملاحظة
   - فتح الملف (محاكاة)
   - فتح المجلد (محاكاة)
   - عرض الفاكس المرتبط (محاكاة)
```

## بنية البيانات المطبقة

### كائن الرد (Reply)
```javascript
{
  // المعرفات
  id: 'reply-1234567890',        // معرف فريد مولّد تلقائياً
  faxId: 'fax-123',              // ربط بالفاكس
  
  // المعلومات الأساسية
  name: 'رد - اسم القالب',       // اسم قابل للتعديل
  templateId: 'template-456' || null,
  templateName: 'اسم القالب' || null,
  fileType: 'docx',              // نوع الملف
  
  // الحالة والتتبع
  status: 'draft',               // draft | in_progress | completed
  createdDate: '2024-01-15T10:30:00',
  lastModified: '2024-01-15T10:30:00',
  
  // اختياري
  note: ''                       // ملاحظة نصية
}
```

## المحاكاة الحالية

العمليات التالية محاكاة وتُعرض كرسائل تنبيه:

1. **إنشاء الملف الفعلي**
   - محاكاة: إنشاء كائن البيانات فقط
   - نهائي: استنساخ القالب أو إنشاء DOCX فارغ

2. **فتح الملف**
   - محاكاة: `alert('سيتم فتح الملف في المرحلة النهائية')`
   - نهائي: `electron.openFile(filePath)`

3. **فتح المجلد**
   - محاكاة: `alert('سيتم فتح المجلد في المرحلة النهائية')`
   - نهائي: `electron.openFolder(folderPath)`

4. **عرض الفاكس المرتبط**
   - محاكاة: `alert('سيتم فتح تفاصيل الفاكس المرتبط')`
   - نهائي: فتح FaxDetailModal للفاكس المرتبط

### 1. الباك إند
```javascript
// API endpoints needed
POST   /api/fax-replies              // إنشاء رد جديد
GET    /api/fax-replies              // جلب جميع الردود
GET    /api/fax-replies/:id          // جلب رد محدد
PUT    /api/fax-replies/:id          // تحديث رد
DELETE /api/fax-replies/:id          // حذف رد
POST   /api/fax-replies/from-template // إنشاء من قالب
```

### 2. Electron APIs
```javascript
// File operations
electron.copyTemplate(templatePath, destinationPath)
electron.createEmptyDocument(destinationPath, type)
electron.openFile(filePath)
electron.openFolder(folderPath)
electron.getFileInfo(filePath)
```

### 3. قاعدة البيانات
```sql
CREATE TABLE fax_replies (
  id VARCHAR(50) PRIMARY KEY,
  fax_id VARCHAR(50) NOT NULL,
  name VARCHAR(255) NOT NULL,
  template_id VARCHAR(50),
  file_path VARCHAR(500) NOT NULL,
  file_type VARCHAR(10) NOT NULL,
  status VARCHAR(20) DEFAULT 'draft',
  note TEXT,
  created_date DATETIME NOT NULL,
  last_modified DATETIME NOT NULL,
  FOREIGN KEY (fax_id) REFERENCES filtered_faxes(id)
);
```
