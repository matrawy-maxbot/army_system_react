# تحديث أيقونات التوجيه في الـ Sidebar

## التحديث
تم استبدال أيقونة السهم البسيط (→) بأيقونة "External Link" / "فتح في صفحة جديدة" في أزرار التوجيه للأقسام التي تنتقل إلى صفحات كاملة.

## الأقسام المُحدثة

### 1. قسم العناصر المثبتة
**الزر:** "فتح صفحة الأرشيف"
**الوجهة:** صفحة الأرشيف الكاملة

### 2. قسم القوائم
**الزر:** "فتح صفحة القوائم"
**الوجهة:** صفحة القوائم الكاملة

## الأيقونة الجديدة

### قبل التحديث (السهم →):
```jsx
<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" strokeWidth="2">
    <path d="M9 6l6 6l-6 6"/>
</svg>
```
- سهم بسيط يشير لليمين
- غير واضح أنه يفتح صفحة

### بعد التحديث (External Link ↗):
```jsx
<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" strokeWidth="2" strokeLinecap="round" strokeLinejoin="round">
    <path d="M18 13v6a2 2 0 0 1-2 2H5a2 2 0 0 1-2-2V8a2 2 0 0 1 2-2h6"/>
    <polyline points="15 3 21 3 21 9"/>
    <line x1="10" y1="14" x2="21" y2="3"/>
</svg>
```
- أيقونة واضحة تدل على "فتح في صفحة" أو "الانتقال"
- سهم قطري مع مربع - معيار عالمي للتوجيه

## ملخص أزرار Sidebar بعد جميع التحديثات

### أزرار الإضافة السريعة (+):
- ✅ **التذكيرات** - زر + لإضافة تذكير
- ✅ **المهمات** - زر + لإضافة مهمة

### أزرار التوجيه (↗):
- ✅ **العناصر المثبتة** - أيقونة external link للأرشيف
- ✅ **القوائم** - أيقونة external link للقوائم

## الفوائد

### 1. وضوح أفضل 🎯
- المستخدم يفهم فوراً أن الزر سينقله لصفحة كاملة
- الأيقونة معيار عالمي معروف

### 2. تمييز واضح 🔄
- **زر +** = إضافة سريعة (في نفس المكان)
- **زر ↗** = فتح صفحة كاملة (انتقال)

### 3. تجربة مستخدم محسنة ✨
- لا لبس بين الإضافة والتوجيه
- الأيقونات تعكس الوظيفة بدقة
