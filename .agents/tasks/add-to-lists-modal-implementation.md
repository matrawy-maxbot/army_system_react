# تنفيذ نظام إضافة العناصر إلى القوائم

## التاريخ
2024-10-29

## الوصف
تم تغيير نظام المفضلة من الإضافة التلقائية إلى نظام اختيار القوائم يدوياً. الآن عند الضغط على زر النجمة (المفضلة) على أي عنصر في البرنامج، يظهر مودال يسمح للمستخدم باختيار قائمة أو عدة قوائم لإضافة العنصر إليها.

## الملفات المنشأة

### 1. AddToListsModal.jsx
**المسار:** `src/components/common/AddToListsModal.jsx`

**الوظائف:**
- عرض قائمة بجميع القوائم المتاحة

- عرض القوائم التي يوجد فيها العنصر حالياً (محددة مسبقاً)

**المميزات:**
- واجهة مستخدم نظيفة وواضحة
- إظهار معلومات القائمة (الاسم، عدد العناصر، قائمة افتراضية)
- رسالة عند عدم وجود قوائم
- معالجة الأخطاء
- حالة تحميل أثناء الحفظ

## بنية البيانات

### العنصر المرسل إلى المودال
```javascript
{
  type: 'fax' | 'originalFax' | 'reply' | 'document',
  id: number,
  // خصائص إضافية حسب النوع:
  fileName: string,      // للفاكس الأصلي
  faxNumber: number,     // للفاكس المفلتر
  name: string          // عام
}
```

### بنية القائمة
```javascript
{
  id: number,
  name: string,
  isDefault: boolean,
  items: [
    {
      type: string,
      itemId: number,
      addedDate: string (ISO)
    }
  ]
}
```

## كيفية الاستخدام

### في الفاكس الأصلي:
```javascript
<OriginalFaxSection 
  onAddToLists={() => {
    if (appState.originalFax) {
      handleAddToLists({
        type: 'originalFax',
        id: appState.originalFax.id,
        fileName: appState.originalFax.fileName
      });
    }
  }}
/>
```

### في الفاكسات المفلترة:
```javascript
<FaxGrid onAddToLists={handleAddToLists} />
```

## التحسينات المستقبلية المحتملة

1. **إضافة قائمة جديدة من داخل المودال**
   - زر "إنشاء قائمة جديدة" في أسفل القائمة
   - فتح مودال فرعي لإدخال اسم القائمة

2. **البحث في القوائم**
   - إضافة حقل بحث عند وجود عدد كبير من القوائم

3. **عرض تفاصيل أكثر**
   - عرض آخر تاريخ تعديل للقائمة
   - عرض معاينة للعناصر الموجودة في القائمة

4. **إشارة بصرية للعناصر في القوائم**
   - تغيير لون أو إضافة علامة على الأيقونات للعناصر الموجودة في أي قائمة

5. **سحب وإفلات**
   - السماح بسحب العناصر مباشرة إلى القوائم
