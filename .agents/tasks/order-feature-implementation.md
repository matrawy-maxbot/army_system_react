## التفاصيل التقنية

### بنية البيانات

كل عنصر (قائمة، تذكير، أو قالب) يحتوي الآن على حقل `order`:

```javascript
{
  id: 123456,
  name: "اسم العنصر",
  order: 0,  // جديد - يبدأ من 0
  // ... باقي الحقول
}
```

### آلية الترتيب

1. **عند التحميل:** العناصر تُرتب حسب `order` تصاعدياً
2. **عند الإضافة:** العنصر الجديد يحصل على `order = maxOrder + 1`
3. **عند التحريك:** يتم تبديل العناصر وإعادة ترقيم `order` لجميع العناصر
4. **عند الحفظ:** يتم حفظ الترتيب الجديد مباشرة في قاعدة البيانات

### دالة التحريك (مثال من القوائم)

```javascript
const moveList = async (listId, direction) => {
    const currentIndex = lists.findIndex(l => l.id === listId);
    const newIndex = direction === 'up' ? currentIndex - 1 : currentIndex + 1;
    
    // تبديل العناصر
    const updatedLists = [...lists];
    [updatedLists[currentIndex], updatedLists[newIndex]] = 
        [updatedLists[newIndex], updatedLists[currentIndex]];
    
    // إعادة ترقيم order
    const listsWithNewOrder = updatedLists.map((list, index) => ({
        ...list,
        order: index
    }));
    
    // حفظ في قاعدة البيانات
    await dataAPI.saveData({ lists: listsWithNewOrder });
};
```

## التصميم والـ UI

### أزرار الترتيب

**القوائم:**
- موقع الأزرار: أسفل البطاقة في منطقة الإجراءات
- التصميم: أزرار صغيرة مع أيقونات سهم
- اللون: رمادي افتراضياً، أزرق عند التمرير

**التذكيرات:**
- موقع الأزرار: أعلى البطاقة بجانب أيقونة الجرس وزر التعديل
- التصميم: أزرار دائرية صغيرة
- الظهور: فقط عند اختيار "الترتيب اليدوي"

**القوالب:**
- موقع الأزرار: في الـ overlay عند التمرير
- التصميم: أزرار مربعة في صف منفصل أعلى الأزرار الأخرى
- اللون: أزرق فاتح مع تأثير hover

## الاختبار

### سيناريوهات الاختبار

1. **إضافة عنصر جديد:**
   - ✅ يظهر في النهاية
   - ✅ يحصل على `order` صحيح

2. **تحريك عنصر للأعلى:**
   - ✅ العنصر يتحرك مكان واحد للأعلى
   - ✅ العنصر الآخر يتحرك للأسفل
   - ✅ الترتيب يُحفظ

3. **تحريك عنصر للأسفل:**
   - ✅ العنصر يتحرك مكان واحد للأسفل
   - ✅ العنصر الآخر يتحرك للأعلى
   - ✅ الترتيب يُحفظ

4. **حدود الترتيب:**
   - ✅ العنصر الأول لا يظهر له سهم للأعلى
   - ✅ العنصر الأخير لا يظهر له سهم للأسفل

5. **الـ Sidebar:**
   - ✅ يعرض العناصر بنفس ترتيب الصفحات
   - ✅ يتحدث تلقائياً عند تغيير الترتيب
