# تحسينات مودال المجلد في صفحة الأرشيف

## التاريخ
7 نوفمبر 2026

## الهدف
تحسين مودال تفاصيل المجلد في صفحة الأرشيف بإضافة ميزات جديدة للتفاعل مع المجلدات والملفات.

## التعديلات المنفذة

### 1. تحسينات الهيدر (Header)
✅ **إضافة أزرار في الهيدر على اليمين يسار العنوان:**
- **زر المفضلة (⭐)**: يفتح مودال إضافة المجلد إلى القوائم
- **زر المسار (📁)**: يفتح مسار المجلد في مستكشف الملفات

الترتيب من اليمين لليسار:
```
[زر المسار] [زر المفضلة] [اسم المجلد] ... [زر الإغلاق ×]
```

### 2. تحسينات الملفات
✅ **إضافة زر المفضلة لكل ملف:**
- أضيف زر المفضلة (⭐) بجانب زر التثبيت في صف كل ملف
- يفتح مودال إضافة الملف إلى القوائم
- تأثيرات hover بلون برتقالي مميز

الترتيب في صف الملف:
```
[Checkbox] [نوع الملف] [اسم الملف] [حجم الملف] [⭐] [📌] [🗑️]
```

### 3. تحسينات إجراءات التحديد (Bulk Actions)
✅ **إضافة أزرار جديدة في شريط الإجراءات الجماعية:**
- **زر نقل الملفات**: ينقل الملفات المحددة إلى مجلد آخر
- تم إزالة زر "إضافة إلى المفضلة" من الإجراءات الجماعية (كل ملف له زر خاص)

الترتيب الجديد:
```
[تم تحديد X] [نقل إلى مجلد] [حذف] [إلغاء التحديد]
```

### 4. مودال نقل الملفات
✅ **مودال جديد لنقل الملفات:**
- يظهر عند الضغط على "نقل إلى مجلد"
- يعرض قائمة بكل الفئات والمجلدات المتاحة
- يمنع نقل الملفات إلى نفس المجلد الحالي
- تصميم نظيف ومنظم مع تجميع حسب الفئات

### 5. فتح مودال تفاصيل الملف
✅ **تغيير سلوك الضغط على الملف:**
- **السلوك القديم**: كان يفتح الملف مباشرة في التطبيق الافتراضي
- **السلوك الجديد**: يفتح مودال تفاصيل الملف (FileDetailModal)
- المودال يحتوي على:
  - معلومات تفصيلية عن الملف
  - زر لفتح الملف
  - خيارات إضافية (تثبيت، حذف، استنساخ، إلخ)

## الملفات المعدلة

### 1. FolderViewModal.jsx
**الإضافات:**
- استيراد `AddToListsModal` و `FileDetailModal`
- إضافة متغيرات حالة جديدة:
  - `showAddToListsModal`
  - `showMoveFilesModal`
  - `showFileDetailModal`
  - `selectedFileForDetail`
  
**الوظائف الجديدة:**
- `handleToggleFolderFavorite()`: فتح مودال القوائم للمجلد
- `handleOpenFolderPath()`: فتح مسار المجلد في المستكشف
- `handleToggleFileFavorite(file)`: فتح مودال القوائم لملف محدد
- `handleMoveSelectedFiles()`: فتح مودال نقل الملفات
- `handleConfirmMoveFiles(targetFolderId)`: تنفيذ عملية النقل
- تعديل `handleOpenFile(file)`: تغيير لفتح مودال التفاصيل بدلاً من فتح الملف

**التعديلات على الهيكل:**
- تحديث هيدر المودال لإضافة الأزرار الجديدة
- إضافة زر المفضلة لكل ملف في القائمة
- تحديث شريط الإجراءات الجماعية
- إضافة المودالات الثلاثة في النهاية:
  - AddToListsModal
  - Move Files Modal
  - FileDetailModal

### 2. FolderViewModal.css
**الأنماط الجديدة:**
- `.fvm-head-left`: محتوى يسار الهيدر
- `.fvm-head-btn`: الأزرار في الهيدر
- `.fvm-head-favorite-btn:hover`: hover للمفضلة
- `.fvm-head-path-btn:hover`: hover للمسار
- `.fvm-favorite-btn`: زر المفضلة في صف الملف
- `.fvm-favorite-btn:hover`: hover بلون برتقالي
- `.fvm-move-dialog`: مودال نقل الملفات
- `.fvm-folder-select-list`: قائمة المجلدات
- `.fvm-folder-select-category`: قسم الفئة
- `.fvm-folder-select-category-name`: اسم الفئة
- `.fvm-folder-select-item`: عنصر مجلد قابل للاختيار
- `.fvm-folder-category-hint`: تلميح اسم الفئة

**التحديثات:**
- تحديث `grid-template-columns` لصف الملف من `60px` إلى `80px` لاستيعاب الزر الإضافي
- تحديث responsive للموبايل

## الميزات التقنية

### إدارة الحالة
- استخدام React hooks (useState)
- التكامل مع AppStateContext
- الحفظ التلقائي بعد كل عملية

### التفاعل مع النظام
- استخدام electronAPI لفتح المسارات
- دعم فتح مودالات متعددة بشكل متداخل
- منع الانتشار (stopPropagation) للأحداث

### تجربة المستخدم
- تأكيد حذف الملفات
- رسائل توضيحية
- أيقونات مميزة لكل إجراء
- تأثيرات hover واضحة
