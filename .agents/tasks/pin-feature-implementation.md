## بنية البيانات

### المجلد المثبت
```javascript
{
  id: 'folder-id',
  name: 'اسم المجلد',
  isPinned: true,  // العلم الجديد
  categoryId: 'category-id',
  files: [...]
}
```

### الملف المثبت
```javascript
{
  id: 'file-id',
  name: 'اسم الملف',
  originalFileName: 'الاسم الأصلي',
  isPinned: true,  // العلم الجديد
  path: 'file-path',
  size: 1024
}
```

### عنصر مثبت في Sidebar
```javascript
{
  type: 'folder' | 'file',
  id: 'item-id',
  name: 'اسم العنصر',
  categoryName: 'اسم الفئة',
  // للمجلدات:
  filesCount: 5,
  // للملفات:
  folderName: 'اسم المجلد',
  folderId: 'folder-id',
  filePath: 'file-path'
}
```

## تدفق العمل

### تثبيت مجلد:
1. المستخدم يضغط على زر التثبيت في بطاقة المجلد
2. `handlePinFolder()` في `ArchivePage` يتم استدعاؤها
3. يتم تحديث `isPinned` للمجلد في `appState.archiveCategories`
4. يتم حفظ البيانات
5. `Sidebar` يستمع للتغييرات ويحدث قائمة العناصر المثبتة تلقائياً

### تثبيت ملف:
1. المستخدم يفتح المجلد ويضغط على زر التثبيت على الملف
2. `handlePinFile()` في `FolderViewModal` يتم استدعاؤها
3. يتم تحديث `isPinned` للملف داخل المجلد
4. يتم حفظ البيانات
5. `Sidebar` يحدّث القائمة تلقائياً

### إلغاء التثبيت من Sidebar:
1. المستخدم يضغط على زر إلغاء التثبيت
2. `handleUnpinItem()` يتم استدعاؤها
3. يتم البحث عن العنصر وتحديث `isPinned` إلى `false`
4. يتم حفظ البيانات
5. العنصر يختفي من القائمة

### فتح عنصر مثبت:
- **مجلد:** الانتقال لصفحة الأرشيف (يمكن تحسينه لفتح المجلد مباشرة)
- **ملف:** فتح الملف باستخدام `electronAPI.openDocument()`

## المزايا

### 1. مرونة أكثر
- يمكن للمستخدمين تثبيت عدة مجلدات وملفات
- ليس محدوداً بعنصر واحد فقط كالقالب اليومي

### 2. وصول سريع
- الوصول المباشر للمجلدات والملفات المهمة من الشريط الجانبي
- لا حاجة للتنقل في الأرشيف للوصول للمحتوى المستخدم بكثرة

### 3. تجربة مستخدم محسّنة
- أزرار تثبيت واضحة مع تأثيرات بصرية
- عرض معلومات السياق (الفئة والمجلد)
- إمكانية إلغاء التثبيت بسهولة

### 4. تكامل سلس
- التكامل مع نظام البيانات الموجود
- لا يتطلب تعديلات في البنية التحتية
- يعمل مع Browser Mode و Electron Mode
