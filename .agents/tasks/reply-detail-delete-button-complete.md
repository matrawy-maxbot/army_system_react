### 2. إضافة دالة حذف الرد
**الموقع**: `src/components/faxes/ReplyDetailModal.jsx` (بعد دالة `confirmDeleteNote`)

**الدوال المضافة**:
```javascript
const handleDeleteReply = () => {
    setShowDeleteReplyModal(true);
};

const confirmDeleteReply = async () => {
    const updatedReplies = replies.filter(r => r.id !== reply.id);
    await updateState({ faxReplies: updatedReplies });
    setShowDeleteReplyModal(false);
    onClose(); // إغلاق المودال بعد الحذف
};
```

**الوظيفة**:
- `handleDeleteReply`: يفتح مودال التأكيد
- `confirmDeleteReply`: يحذف الرد من القائمة، يحدث الحالة، يغلق المودال

- رسالة تحذير واضحة عن حذف المحتويات
- تأكيد مزدوج قبل الحذف

## ترتيب الأزرار في الفوتر

من اليمين إلى اليسار:
1. **فتح الملف** - زر أساسي (primary)
2. **حذف الرد** - زر خطر (danger) - **جديد**
3. **إغلاق** - زر ثانوي (secondary)

## تجربة المستخدم

### سيناريو الحذف:
1. المستخدم يفتح مودال تفاصيل الرد
2. يضغط على زر "حذف الرد" في الفوتر
3. يظهر مودال تأكيد يحتوي على:
   - عنوان: "تأكيد حذف الرد"
   - رسالة: "هل أنت متأكد من حذف هذا الرد نهائياً؟"
   - اسم الرد
   - تحذير: "سيتم حذف الرد وجميع محتوياته (ملاحظات، مرفقات) ولا يمكن التراجع عن هذا الإجراء"
   - زرين: "تأكيد الحذف" (danger) و "إلغاء"
4. عند التأكيد:
   - يتم حذف الرد من القائمة
   - يتم تحديث الحالة
   - يتم إغلاق مودال التأكيد
   - يتم إغلاق مودال تفاصيل الرد
5. عند الإلغاء:
   - يتم إغلاق مودال التأكيد فقط
   - يبقى مودال تفاصيل الرد مفتوحاً
