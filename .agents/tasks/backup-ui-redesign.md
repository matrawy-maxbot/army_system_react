- **الخط الرئيسي**: IBM Plex Sans Arabic

### 4. الهيكل الجديد

#### الـ Header
- عنوان بسيط "النسخ الاحتياطية"
- زر "إنشاء نسخة" أنيق مع أيقونة +
- بدون أيقونة كبيرة أو نص فرعي

#### لوحة القائمة (List Panel)
- رأس يحتوي على:
  - عنوان "النسخ" مع عداد (مثال: (3))
  - حقل بحث صغير ومرتب
- قائمة النسخ الاحتياطية
- تذييل يعرض "3 من 10 نسخ"

#### صفوف النسخ
كل صف يحتوي على:
- **أيقونة سحابة** صغيرة (37×37 بكسل) بخلفية زرقاء فاتحة
- **اسم النسخة** بخط واضح
- **معلومات ثانوية**: التاريخ والحجم (نص صغير رمادي)
- **زر استعادة**: أزرق مع أيقونة
- **زر حذف**: أحمر مع أيقونة
