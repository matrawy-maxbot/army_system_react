## البنية والوظائف

### نافذة التفاصيل (FaxDetailModal)

#### Header Section
```
┌─────────────────────────────────────────┐
│ [اسم الفاكس] ✏️  [⭐] [📁] [🗑️]      │
└─────────────────────────────────────────┘
```

#### معاينة الصور
```
┌─────────────────────────────────────────┐
│          ←  [صورة كبيرة]  →             │
│           1 / 5  [تابعة]                │
└─────────────────────────────────────────┘
```

#### الصور المصغرة
```
┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐
│ 1│ │ 2│ │ 3│ │ 4│ │ 5│  ← أساسية
└──┘ └──┘ └──┘ └──┘ └──┘

───── الصفحات التابعة ─────

┌──┐ ┌──┐
│ 6│ │ 7│  ← تابعة
└──┘ └──┘
```

#### الملاحظات
```
[+ إضافة ملاحظة]

أو

┌─────────────────────────────────────────┐
│ الملاحظة:                               │
│ نص الملاحظة هنا...                      │
└─────────────────────────────────────────┘
```

### التحديد الجماعي

#### بدون تحديد:
```
الفاكسات المفلترة (5)  [تحديد الكل]
```

#### مع تحديد:
```
الفاكسات المفلترة (5)  [3 محدد] [إلغاء التحديد] [🗑️ حذف المحدد]
```

## حالات الاستخدام

### 1. فتح تفاصيل الفاكس
```
المستخدم: ينقر على بطاقة فاكس
النظام: يفتح FaxDetailModal
النتيجة: معاينة كاملة مع جميع الأدوات
```

### 2. تعديل اسم الفاكس
```
المستخدم: ينقر على أيقونة القلم
النظام: يعرض input للتعديل
المستخدم: يدخل اسم جديد ويضغط ✓
النتيجة: يتم حفظ الاسم الجديد
```

### 3. إضافة ملاحظة
```
المستخدم: ينقر "إضافة ملاحظة"
النظام: يعرض textarea
المستخدم: يكتب الملاحظة ويضغط "حفظ"
النتيجة: تظهر الملاحظة
```

### 4. تصفح الصور
```
المستخدم: ينقر → أو ←
النتيجة: تتغير الصورة المعروضة

المستخدم: ينقر على صورة مصغرة
النتيجة: تعرض الصورة في المعاينة الكبيرة
```

### 5. حذف فاكس
```
المستخدم: ينقر زر الحذف 🗑️
النظام: يعرض تأكيد
المستخدم: يؤكد
النتيجة: يحذف الفاكس ويغلق المودال
```

### 6. تحديد جماعي
```
المستخدم: ينقر "تحديد الكل"
النتيجة: تحديد جميع الفاكسات

المستخدم: ينقر "حذف المحدد"
النظام: يعرض تأكيد مع العدد
المستخدم: يؤكد
النتيجة: حذف جميع الفاكسات المحددة
```

## الأيقونات المستخدمة

| الوظيفة | الأيقونة | الموقع |
|---------|----------|---------|
| تعديل الاسم | ✏️ قلم | بجوار الاسم |
| المفضلة | ⭐ نجمة | Header |
| فتح المجلد | 📁 مجلد | Header |
| حذف | 🗑️ سلة مهملات | Header |
| صح | ✓ علامة صح | تعديل الاسم |
| إلغاء | ✕ علامة X | تعديل الاسم |
| سابق | ← سهم يسار | معاينة الصور |
| تالي | → سهم يمين | معاينة الصور |
| إضافة | + علامة زائد | إضافة ملاحظة |
